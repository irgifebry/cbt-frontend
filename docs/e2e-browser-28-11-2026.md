## Temuan

**Jawaban unggah tidak serializable — sudah diperbaiki.** Semula `File` diteruskan langsung ke adapter dan menjadi `{}` setelah `JSON.stringify`, sehingga jawaban tidak bertahan. Perbaikan: `src/lib/jawabanUpload.js` menormalisasi `File` menjadi `jawaban.name` sebelum autosave; `SoalInput` memakai fungsi tersebut. Uji ulang browser: `jawabanTersimpan: "cbt-e2e-bukti-fix.txt"` (string), tampilan `Berkas dipilih: ...` tetap benar, dan nilainya bertahan setelah reload. Validasi format/ukuran **tetap sengaja tidak diterapkan** (Q06 masih terbuka).

## Pengamatan lain

- Tidak ada halaman hasil yang diaktifkan; tidak ada kunci jawaban yang ditampilkan ke peserta.
- Tidak ada peringatan, penalti, atau penghentian ujian akibat event proctor — event hanya dicatat.
- Bobot total di bawah 100 tidak dinormalisasi; aturan attempt, koreksi pasca-publikasi, dan timer tidak diubah.
- Tidak ada perubahan pada `lms-backend`, `lms-frontend`, `lms-mobile`, atau alur `link_cbt`/`token_cbt`/`nilai_cbt`.
- Konsol browser menampilkan `Gagal mengambil data profil: AxiosError: Network Error` dari layout LMS lama karena backend LMS tidak dijalankan; error ini sudah ada sebelumnya dan tidak diubah dalam pengujian ini.

## Cara mengulang

```bash
cd cbt-frontend
npm run dev -- --host 127.0.0.1
S=$(agent-browser session id --scope worktree --prefix e2e-ulang)
agent-browser --session "$S" open http://127.0.0.1:5173/cbt
agent-browser --session "$S" snapshot -i -c
```

Untuk peran instruktur, dari session terpisah:

```bash
agent-browser --session "$S2" eval --stdin <<'EOF'
localStorage.setItem('user_token','token-contoh');
localStorage.setItem('user_role','dosen');
EOF
```
